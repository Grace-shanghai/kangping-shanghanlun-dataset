# 康平本《伤寒论》字符锚点数据包 v1.0

> 一句话：**每一句都指得出它在哪一页、哪一列、第几行起的。**

## 一、这是什么

《古本康平伤寒论》全书 **124 页**的逐列录入，共 **874 个单元**。
每个单元就是“一列字”，带三样东西：**位置（页-列）**、**层级（低格）**、**语流（谁在说话）**。

**它不是校注本，是底本数据的公开版。**不改字、不解释、不涉诊疗。

## 二、目录

```
pages/pNNN.csv    每页一档（124 个）
pages/pNNN.json   页元数据：页号、列数、字数、各级分布
all.csv           全书 874 条汇总
README.md         本文件
```

## 三、字段

| 字段 | 含义 |
|---|---|
| `page` | 页码 1—124 |
| `col` | 列号，**自右向左**，1 为最右一列 |
| `level` | **低格**：0＝顶格／1＝降一格／2＝降二格／3＝篇题层；**空＝悬空** |
| `text` | 原文（保留原标点） |
| `first` / `last` | 首字／末字（便于定位） |
| `chars` | 汉字数（不含标点） |
| `flow` | **语流**：经条／方区／论／注／篇题／序 |
| `note` | 校记（含“悬空”原因、异文、待核项） |

## 四、三个关键概念

**① 低格**
该列首字所在行，减去本页最高行。
**0＝顶格（经），1＝降一格（门人），2＝降二格（注），3＝篇题。**

**② 悬空**
有 **39 处**的低格暂未量定（集中在 p25—p30）。
**——我们不给它编一个数，标“悬空”，并在 note 里写明原因。**

**③ 六语流**
经条 519｜方区 254｜论 70｜篇题 13｜序 13｜注 2（另有 84 处圈注嵌在条内）。

## 五、已知缺口（先说清楚）

| 缺口 | 说明 |
|---|---|
| **悬空 39 处** | p25—p30 低格待量 |
| **注层未独立** | 多数注并入“论”，仅 2 条独立成条 |
| **标点非原貌** | 录入所用标点为比对之需，**不主张著作权**，不作校勘依据 |
| **不含影印** | 本包只含文字与位置，不含任何书影 |

## 八、校验

配套 `verify.py` 可核五项：低格合法性、字数、列号连续、顶格存在、跨列提示。

```bash
python verify.py 18     # 校验第 18 页
python verify.py all    # 全书
```
